# Day 27: Getting a Haircut（美容院（びよういん）で）

### ① シナリオ導入（どうにゅう）
Getting a haircut in Japan is one of the most anxiety-inducing situations for foreigners — one wrong word and you leave with a completely different hairstyle. Today you'll learn exactly how to describe what you want.

**今日（きょう）のゴール**: 美容院（びよういん）でなりたいヘアスタイルを伝え（つたえ）られるようになる

### ② キーフレーズ & 文法（ぶんぽう）

- **カットをお願い（ねがい）します** — A haircut, please
- **少し（すこし）短く（みじかく）してください** — Please cut it a little shorter
- **〜センチくらい切っ（きっ）てください** — Please cut about ~ centimeters
- **このくらいの長さ（ながさ）で** — About this length
- **写真（しゃしん）を見せ（みせ）てもいいですか？** — Can I show you a photo?
- **いい感じ（かんじ）です** — Looks good / That's nice

💡 文法（ぶんぽう）ポイント: 「〜にしてください」で希望（きぼう）のスタイルを伝え（つたえ）る。「前髪（まえがみ）を短く（みじかく）してください」「横（よこ）は刈り（かり）上げ（あげ）にしてください」

### ③ モデル会話（かいわ）

**美容師（びようし）**: いらっしゃいませ。今日は（こんにちは）どうされますか？
**客（きゃく）**: カットをお願い（ねがい）します。
**美容師（びようし）**: どんな感じ（かんじ）にしますか？
**客（きゃく）**: 全体的（ぜんたいてき）に少し（すこし）短く（みじかく）したいです。写真（しゃしん）を見せ（みせ）てもいいですか？
**美容師（びようし）**: もちろん、見せ（みせ）てください。...なるほど、この感じ（かんじ）ですね。
**客（きゃく）**: はい。横（よこ）と後ろ（うしろ）は短め（みじかめ）で、上（うえ）はあまり切ら（きら）ないでください。
**美容師（びようし）**: 前髪（まえがみ）はどうしますか？
**客（きゃく）**: 前髪（まえがみ）は目に（めに）かからないくらいにしてください。
**美容師（びようし）**: わかりました。じゃあ、始め（はじめ）ますね。

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（易）**
1. A haircut, please. → カットをお願い（ねがい）します。
2. A little shorter, please. → 少し（すこし）短く（みじかく）してください。
3. Please cut about 3 centimeters. → 3センチくらい切っ（きっ）てください。
4. Can I show you a photo? → 写真（しゃしん）を見せ（みせ）てもいいですか？
5. Looks good! → いい感じ（かんじ）です！

**Set 2（中）**
1. I want to keep the top longer and cut the sides shorter. → 上（うえ）は長め（ながめ）のままで、横（よこ）は短く（みじかく）したいです。
2. Please don't cut the bangs too short. → 前髪（まえがみ）はあまり短く（みじかく）しないでください。
3. Just a trim, please. → 整え（ととのえ）るくらいでお願い（ねがい）します。
4. About this length. (showing with fingers) → このくらいの長さ（ながさ）でお願い（ねがい）します。
5. How long will it take? → どのくらい時間（じかん）がかかりますか？

**Set 3（難）**
1. I want something like this photo, but I'm not sure if it'll suit my face shape. What do you think? → この写真（しゃしん）みたいにしたいんですけど、自分（じぶん）の顔（かお）の形（かたち）に合う（あう）かどうかわからなくて。どう思い（おもい）ますか？
2. The last time I got a haircut, they cut it too short. So this time I want it a bit longer. → 前回（ぜんかい）切り（きり）すぎちゃったので、今回（こんかい）はもう少し（すこし）長め（ながめ）でお願い（ねがい）します。
3. I don't use hair wax, so I'd like a style that looks good without any styling. → ワックスを使わ（つかわ）ないので、セットしなくてもいい感じ（かんじ）になるスタイルにしてほしいです。
4. Could you thin it out a bit? My hair is really thick. → すいてもらえますか？髪（かみ）が多い（おおい）ので。
5. I'm going to a wedding next week, so could you make it look a bit more formal? → 来週（らいしゅう）結婚式（けっこんしき）があるので、少し（すこし）フォーマルな感じ（かんじ）にしてもらえますか？

### ⑤ AI練習（れんしゅう）テンプレート
