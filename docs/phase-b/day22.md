# Day 22: At the Post Office（郵便局（ゆうびんきょく）で）

### ① シナリオ導入（どうにゅう）
You want to send a package to your family back home, or maybe just mail a letter. The Japanese post office has specific procedures and questions — weight, destination, speed, insurance. Today you'll learn to handle it all.

**今日（きょう）のゴール**: 郵便局（ゆうびんきょく）で荷物（にもつ）を送る（おくる）手続き（てつづき）が一通り（ひととおり）できるようになる

### ② キーフレーズ & 文法（ぶんぽう）

- **〜を送り（おくり）たいんですけど** — I'd like to send ~
- **〜まで何日（なんにち）かかりますか？** — How many days to ~?
- **EMSと船便（ふなびん）、どちらが〜** — EMS or surface mail, which ~?
- **中身（なかみ）は何で（なんで）すか？** — What are the contents?
- **壊れ物（こわれもの）はありますか？** — Is there anything fragile?
- **書留（かきとめ）にしますか？** — Would you like it registered?

💡 文法（ぶんぽう）ポイント: 「〜んですけど」は窓口（まどぐち）での定型（ていけい）パターン。理由（りゆう）や状況（じょうきょう）を説明し（せつめいし）てからお願い（ねがい）につなげる。「アメリカに荷物（にもつ）を送り（おくり）たいんですけど」

### ③ モデル会話（かいわ）

**局員（きょくいん）**: 次の（つぎの）方（ほう）、どうぞ。
**客（きゃく）**: アメリカに荷物（にもつ）を送り（おくり）たいんですけど。
**局員（きょくいん）**: EMSと航空便（こうくうびん）がございますが、どちらにしますか？
**客（きゃく）**: 何日（なんにち）くらいかかりますか？
**局員（きょくいん）**: EMSだと3-5日（にち）、航空便（こうくうびん）だと1-2週間（しゅうかん）です。
**客（きゃく）**: EMSでお願い（ねがい）します。
**局員（きょくいん）**: 中身（なかみ）は何で（なんで）すか？
**客（きゃく）**: お菓子（かし）と本（ほん）です。
**局員（きょくいん）**: 壊れ物（こわれもの）はありますか？
**客（きゃく）**: いいえ、ないです。
**局員（きょくいん）**: 重さ（おもさ）が2.3キロなので、5,400円（えん）になります。こちらに送り先（おくりさき）の住所（じゅうしょ）を書い（かい）てください。
**客（きゃく）**: わかりました。

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（易）**
1. I'd like to send this to America. → これをアメリカに送り（おくり）たいんですけど。
2. How many days will it take? → 何日（なんにち）かかりますか？
3. The contents are snacks and books. → 中身（なかみ）はお菓子（かし）と本（ほん）です。
4. There's nothing fragile. → 壊れ物（こわれもの）はないです。
5. By EMS, please. → EMSでお願い（ねがい）します。

**Set 2（中）**
1. Which is cheaper, EMS or airmail? → EMSと航空便（こうくうびん）、どちらが安い（やすい）ですか？
2. I'd like to send this as registered mail. → 書留（かきとめ）で送り（おくり）たいんですけど。
3. Please write the destination address here. → こちらに送り先（おくりさき）の住所（じゅうしょ）を書い（かい）てください。
4. The total is 5,400 yen. → 5,400円（えん）になります。
5. I'd like to buy five 84-yen stamps. → 84円（えん）切手（きって）を5枚（まい）ください。

**Set 3（難）**
1. I want to send this as cheaply as possible. What's the cheapest option? → できるだけ安く（やすく）送り（おくり）たいんですけど、一番（いちばん）安い（やすい）方法（ほうほう）は何で（なんで）すか？
2. Is there an insurance option? The contents are valuable. → 保険（ほけん）はつけられますか？中身（なかみ）が高い（たかい）ものなので。
3. Can I send food to America? Are there any restrictions? → アメリカに食べ物（たべもの）は送れ（おくれ）ますか？制限（せいげん）はありますか？
4. Could I get a tracking number? I want to check the delivery status. → 追跡（ついせき）番号（ばんごう）はもらえますか？配達（はいたつ）の状況（じょうきょう）を確認し（かくにんし）たいんです。
5. I sent a package last week but it hasn't arrived yet. Can you check? → 先週（せんしゅう）荷物（にもつ）を送っ（おくっ）たんですけど、まだ届い（とどい）ていないみたいです。調べ（しらべ）てもらえますか？
