# Day 25: Talking About Money（お金（きん）の話（はなし））

### ① シナリオ導入（どうにゅう）
Splitting the bill, budgeting, talking about prices — money comes up in conversation more than you'd think. Today you'll learn to discuss costs, compare prices, and handle money-related situations naturally.

**今日（きょう）のゴール**: お金（きん）に関す（かんす）る会話（かいわ）（割り勘（わりかん）、値段（ねだん）比較（ひかく）、予算（よさん））を自然（しぜん）にこなせる

### ② キーフレーズ & 文法（ぶんぽう）

- **割り勘（わりかん）にしましょう** — Let's split the bill
- **おごります / おごるよ** — It's my treat / I'll pay
- **〜は高い（たかい） / 安い（やすい） / お得（え）** — ~ is expensive / cheap / a good deal
- **〜円（えん）くらい** — about ~ yen
- **予算（よさん）は〜くらいです** — My budget is about ~
- **現金（げんきん）のみ** — Cash only

💡 文法（ぶんぽう）ポイント: 「おごる」は全額（ぜんがく）払う（はらう）こと。「今日は（こんにちは）私（わたし）がおごります」= "Today's on me." 日本（にほん）では先輩（せんぱい）・年上（としうえ）がおごる文化（ぶんか）がある。

**A**: 今日（きょう）のランチ、おいしかったね。
**B**: うん、おいしかった。いくらだった？
**A**: 2人（にん）で3,600円（えん）。割り勘（わりかん）にしよう。
**B**: 1,800円（えん）ずつだね。あ、現金（げんきん）しかないんだけど大丈夫（だいじょうぶ）？
**A**: うん、大丈夫（だいじょうぶ）。あ、でもこの店（みせ）PayPayも使え（つかえ）るよ。
**B**: じゃあ、PayPayで払う（はらう）。便利（べんり）だね。
**A**: 最近（さいきん）はどこでも電子（でんし）マネーが使え（つかえ）るから、現金（げんきん）あんまりいらないよね。
**B**: 確かに（たしかに）。でも、たまに現金（げんきん）のみの店（みせ）があるから、ちょっとは持っ（もっ）ておかないと。

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（易）**
1. Let's split the bill. → 割り勘（わりかん）にしましょう。
2. It's my treat today. → 今日は（こんにちは）私（わたし）がおごります。
3. This is expensive. → これは高い（たかい）です。
4. That's a good deal. → それはお得（え）ですね。
5. Cash only. → 現金（げんきん）のみです。

**Set 2（中）**
1. It's 3,600 yen total, so 1,800 yen each. → 全部（ぜんぶ）で3,600円（えん）だから、1人（にん）1,800円（えん）ずつだね。
2. My budget is about 10,000 yen. → 予算（よさん）は1万円（まんえん）くらいです。
3. How much is it per person? → 1人（にん）いくらですか？
4. Is this place expensive? → ここって高い（たかい）ですか？
5. Can I pay with PayPay? → PayPayで払え（はらえ）ますか？

**Set 3（難）**
1. This apartment is 80,000 yen per month, which is cheap for this area. → このアパートは月（がつ）8万円（まんえん）で、この辺り（あたり）では安い（やすい）方（ほう）です。
2. I bought it on sale — it was 50% off, so only 2,000 yen. → セールで50%オフだったので、2,000円（えん）で買い（かい）ました。
3. Living expenses in Tokyo are higher than I expected, especially rent. → 東京（とうきょう）の生活費（せいかつひ）は思った（おもった）より高い（たかい）です。特に（とくに）家賃（やちん）が。
4. You don't need to pay me back — it was only a small amount. → 返さ（かえさ）なくていいよ。少し（すこし）だったし。
5. I overspent this month, so I'm trying to save next month. → 今月（こんげつ）使い（つかい）すぎたから、来月（らいげつ）は節約（せつやく）しようと思って（おもって）います。
