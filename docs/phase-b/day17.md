# Day 17: Taking the Train（電車（でんしゃ）に乗る（のる））

### ① シナリオ導入（どうにゅう）
Tokyo's train system is incredible — and incredibly confusing. You need to ask which line to take, where to transfer, and which platform to go to. Today you'll learn to navigate confidently.

**今日（きょう）のゴール**: 電車（でんしゃ）の乗り換え（のりかえ）・行き先（いきさき）を尋ね（たずね）られるようになる

### ② キーフレーズ & 文法（ぶんぽう）

- **〜線（せん）** — ~ Line (Yamanote-sen, Chuo-sen)
- **〜行き（いき）** — bound for ~ (Shibuya-yuki)
- **乗り換え（のりかえ）** — transfer
- **〜番線（ばんせん）** — platform number ~
- **何駅（なにえき）目で（めで）すか？** — How many stops is it?
- **〜で降り（おり）ます** — I'll get off at ~

💡 文法（ぶんぽう）ポイント: 「〜行き（いき）」は行き先（いきさき）を表す（あらわす）。「渋谷（しぶや）行き（いき）の電車（でんしゃ）」= "the train bound for Shibuya." 駅（えき）のアナウンスで頻出（ひんしゅつ）。

### ③ モデル会話（かいわ）

**客（きゃく）**: すみません、渋谷（しぶや）に行き（いき）たいんですけど、何線（なにせん）に乗れ（のれ）ばいいですか？
**駅員（えきいん）**: 渋谷（しぶや）ですね。山手線（やまのてせん）の外回り（そとまわり）に乗って（のって）ください。3番線（ばんせん）です。
**客（きゃく）**: 3番線（ばんせん）ですね。乗り換え（のりかえ）はいりますか？
**駅員（えきいん）**: いいえ、乗り換え（のりかえ）なしで行け（いけ）ますよ。
**客（きゃく）**: 何駅（なにえき）目で（めで）すか？
**駅員（えきいん）**: ここから4駅（えき）目で（めで）す。だいたい10分く（わく）らいです。
**客（きゃく）**: ありがとうございます。あと、Suicaにチャージしたいんですけど。
**駅員（えきいん）**: あそこの機械（きかい）でできますよ。

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（易）**
1. I want to go to Shibuya. → 渋谷（しぶや）に行き（いき）たいです。
2. Which line should I take? → 何線（なにせん）に乗れ（のれ）ばいいですか？
3. Which platform? → 何番線（なんばんせん）ですか？
4. Do I need to transfer? → 乗り換え（のりかえ）はいりますか？
5. How many stops? → 何駅（なにえき）目で（めで）すか？

**Set 2（中）**
1. Please take the Yamanote Line outbound from platform 3. → 3番線（ばんせん）から山手線（やまのてせん）の外回り（そとまわり）に乗って（のって）ください。
2. You don't need to transfer — it goes directly. → 乗り換え（のりかえ）なしで行け（いけ）ますよ。
3. I'd like to charge my Suica. Where can I do that? → Suicaにチャージしたいんですけど、どこでできますか？
4. Is this the train bound for Shinjuku? → これは新宿行（しんじゅくいき）きですか？
5. I'll get off at the next station. → 次の（つぎの）駅（えき）で降り（おり）ます。

**Set 3（難）**
1. I want to go to Odaiba. Which route would be the fastest? → お台場（だいば）に行き（いき）たいんですけど、一番（いちばん）早い（はやい）ルートはどれですか？
2. Transfer to the Ginza Line at Akasakamitsuke — is that correct? → 赤坂見附（あかさかみつけ）で銀座線（ぎんざせん）に乗り換え（のりかえ）るんですよね？
3. I missed my stop. What should I do? → 降り（おり）る駅（えき）を過ぎ（すぎ）てしまいました。どうすればいいですか？
4. Is there an express train? Or should I take the local? → 急行（きゅうこう）はありますか？それとも各駅停車（かくえきていしゃ）の方が（ほうが）いいですか？
5. I got on the wrong train. How do I get to Tokyo Station from here? → 間違え（まちがえ）て違う（ちがう）電車（でんしゃ）に乗って（のって）しまいました。ここから東京駅（とうきょうえき）にはどうやって行け（いけ）ますか？
