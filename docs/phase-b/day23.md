# Day 23: Making a Reservation（予約（よやく）する）

### ① シナリオ導入（どうにゅう）
Restaurant reservations, hotel bookings, doctor's appointments — reservations are a core life skill in Japan. Today you'll learn the standard flow: date, time, number of people, name, phone number.

**今日（きょう）のゴール**: 電話（でんわ）やオンラインで予約（よやく）を取れ（とれ）るようになる

### ② キーフレーズ & 文法（ぶんぽう）

- **予約（よやく）をしたいんですけど** — I'd like to make a reservation
- **〜月（がつ）〜日（にち）の〜時に（ときに）** — On [month] [day] at [time]
- **〜名で（めいで）** — For ~ people
- **空い（あい）ていますか？** — Is it available?
- **名前（なまえ）は〜です** — My name is ~
- **キャンセルしたいんですけど** — I'd like to cancel

💡 文法（ぶんぽう）ポイント: 予約（よやく）は情報（じょうほう）を順番（じゅんばん）に伝え（つたえ）るだけ。日付（ひづけ） → 時間（じかん） → 人数（にんずう） → 名前（なまえ） → 電話番号（でんわばんごう）。このパターンを覚え（おぼえ）れば応用（おうよう）がきく。

### ③ モデル会話（かいわ）

**店（みせ）**: お電話（でんわ）ありがとうございます。〇〇レストランです。
**客（きゃく）**: すみません、予約（よやく）をしたいんですけど。
**店（みせ）**: ありがとうございます。いつがよろしいですか？
**客（きゃく）**: 来週（らいしゅう）の土曜日（どようび）、7時（じ）は空い（あい）ていますか？
**店（みせ）**: 土曜日（どようび）の7時（じ）ですね。何名（なんめい）様（さま）ですか？
**客（きゃく）**: 4名で（めいで）す。
**店（みせ）**: 4名様（めいさま）ですね。お席（せき）ご用意（ようい）できます。お名前（なまえ）とお電話番号（でんわばんごう）をお願い（ねがい）します。
**客（きゃく）**: サム・ウィルソンです。電話番号（でんわばんごう）は080-1234-5678です。
**店（みせ）**: サム・ウィルソン様（さま）、土曜日（どようび）7時（じ）、4名様（めいさま）でお取り（とり）しました。
**客（きゃく）**: ありがとうございます。あ、個室（こしつ）はありますか？
**店（みせ）**: 申し訳（もうしわけ）ございません、個室（こしつ）は予約（よやく）が埋ま（うま）っておりまして...。
**客（きゃく）**: わかりました。大丈夫（だいじょうぶ）です。よろしくお願い（ねがい）します。

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（易）**
1. I'd like to make a reservation. → 予約（よやく）をしたいんですけど。
2. For this Saturday at 7 PM. → 今週（こんしゅう）の土曜日（どようび）の7時（じ）に。
3. For three people. → 3名で（めいで）す。
4. Is it available? → 空い（あい）ていますか？
5. My name is Sam. → サムです。

**Set 2（中）**
1. Is next Saturday at 7 available? → 来週（らいしゅう）の土曜日（どようび）の7時（じ）は空い（あい）ていますか？
2. Do you have a private room? → 個室（こしつ）はありますか？
3. I'd like to cancel my reservation. → 予約（よやく）をキャンセルしたいんですけど。
4. I'd like to change the time from 7 to 8. → 7時（じ）から8時（じ）に時間（じかん）を変更（へんこう）したいんですけど。
5. I made a reservation under the name Sam. → サムという名前（なまえ）で予約（よやく）しています。

**Set 3（難）**
1. I'd like a table by the window if possible. → できれば窓側（まどがわ）の席（せき）がいいんですけど。
2. We have one person with a wheelchair — is that okay? → 車椅子（くるまいす）の人（にん）が1人（にん）いるんですけど、大丈夫（だいじょうぶ）ですか？
3. If 7 is full, what time is available? → 7時（じ）がいっぱいだったら、何時（なんじ）なら空い（あい）ていますか？
4. We might have one more person join us. Can I change the number later? → あと1人（にん）増え（ふえ）るかもしれないんですけど、後（のち）から人数（にんずう）を変更（へんこう）できますか？
5. I reserved for last Saturday by mistake. Could you change it to this Saturday? → 間違え（まちがえ）て先週（せんしゅう）の土曜日（どようび）で予約（よやく）してしまいました。今週（こんしゅう）の土曜日（どようび）に変更（へんこう）できますか？

### ⑤ AI練習（れんしゅう）テンプレート

```
あなたは人気のある日本料理レストランの受付スタッフです。電話対応をしてください。

私が電話で予約をします。

ルール:
- 「お電話ありがとうございます。〇〇でございます」から始めてください
- 日時、人数、名前、電話番号を順番に確認してください
- 希望の日時が埋まっている場合は代替を提案してください
- 私が追加のリクエスト（個室、窓側等）をしたら対応してください
- 5-7往復の会話をしましょう
- 最後に、私の予約会話で良かった点と改善点を1つずつ教えてください
```
