# Day 12: Giving Reasons（理由（りゆう）を説明す（せつめいす）る）

### ① シナリオ導入（どうにゅう）
"Why?" is one of the most common questions. Today you'll learn to explain reasons — why you're late, why you chose something, why you like Japan. Connecting ideas with reasons makes your Japanese sound dramatically more natural.

**今日（きょう）のゴール**: 「なぜ」に対し（たいし）て自然（しぜん）に理由（りゆう）を説明（せつめい）できるようになる

### ② キーフレーズ & 文法（ぶんぽう）

- **〜から** — because ~ (reason at the end)
- **〜ので** — because ~ (softer/more polite)
- **〜て** — and so / because (casual connection)
- **だから** — that's why / so (at the beginning of a sentence)
- **〜のは〜からです** — The reason ~ is because ~
- **〜ためです** — It's for the purpose of ~ / It's because of ~

💡 文法（ぶんぽう）ポイント: 「から」と「ので」の使い分け（つかいわけ）。「から」は主観的（しゅかんてき）理由（りゆう）（個人的な（こじんてきな）気持ち（きもち））、「ので」は客観的（きゃっかんてき）理由（りゆう）（事実（じじつ））。ビジネスでは「ので」がベター。

**A**: どうして日本語（にほんご）を勉強（べんきょう）しているんですか？
**B**: 日本（にほん）のアニメが好き（すき）で、字幕（じまく）なしで見た（みた）いと思った（おもった）からです。
**A**: なるほど。日本（にほん）に住み（すみ）たいですか？
**B**: はい。日本（にほん）の文化（ぶんか）が好き（すき）なので、いつか住み（すみ）たいです。
**A**: 東京（とうきょう）と大阪（おおさか）、どっちがいいですか？
**B**: 大阪（おおさか）がいいです。食べ物（たべもの）がおいしいし、人（にん）もフレンドリーなので。
**A**: いい選択（せんたく）ですね。大阪（おおさか）は生活費（せいかつひ）も東京（とうきょう）より安い（やすい）ですしね。

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（易）**
1. I'm tired because I worked a lot. → たくさん働い（はたらい）たので、疲れ（つかれ）ました。
2. I like Japan because the food is delicious. → 食べ物（たべもの）がおいしいから、日本（にほん）が好き（すき）です。
3. I was late because of the train. → 電車（でんしゃ）のせいで遅れ（おくれ）ました。
4. That's why I started studying Japanese. → だから日本語（にほんご）を勉強（べんきょう）し始め（はじめ）ました。
5. I can't go because I'm busy. → 忙しい（いそがしい）ので、行け（いけ）ないです。

**Set 2（中）**
1. I chose this restaurant because it had good reviews. → 口コミ（くちこみ）がよかったので、このレストランにしました。
2. The reason I want to live in Japan is because I love the culture. → 日本（にほん）に住み（すみ）たいのは、文化（ぶんか）が好き（すき）だからです。
3. It's raining, so let's take a taxi. → 雨（あめ）が降っ（ふっ）ているので、タクシーに乗り（のり）ましょう。
4. I study every day because I want to pass JLPT. → JLPTに受か（うか）りたいから、毎日（まいにち）勉強（べんきょう）しています。
5. Osaka is good because the food is great and the people are friendly. → 大阪（おおさか）は食べ物（たべもの）がおいしいし、人（にん）もフレンドリーなのでいいです。

**Set 3（難）**
1. I started learning Japanese because I wanted to watch anime without subtitles, but now I'm into it for many other reasons too. → 字幕（じまく）なしでアニメを見た（みた）くて日本語（にほんご）を始め（はじめ）ましたけど、今（いま）は他に（ほかに）もいろいろな理由（りゆう）でハマっています。
2. The reason I moved to Tokyo is because I got a job offer from a Japanese company. → 東京（とうきょう）に引っ越し（ひっこし）たのは、日本（にほん）の会社（かいしゃ）からオファーをもらったからです。
3. I didn't go to the party because I wasn't feeling well, and also because I had work early the next morning. → 体調（たいちょう）が悪か（わるか）ったのと、次の（つぎの）日朝（にっちょう）早く（はやく）仕事（しごと）だったので、パーティーに行き（いき）ませんでした。
4. In order to improve my Japanese, I try to think in Japanese as much as possible. → 日本語（にほんご）を上達（じょうたつ）させるために、できるだけ日本語（にほんご）で考え（かんがえ）るようにしています。
5. I prefer the countryside because it's quieter, but you need a car, which is inconvenient. → 静か（しずか）なので田舎（いなか）の方が（ほうが）好き（すき）ですけど、車（くるま）がないと不便（ふべん）なのが困り（こまり）ます。

### ⑤ AI練習（れんしゅう）テンプレート

```
あなたは好奇心旺盛な日本人の大学生「あおい」です。外国人の日本語学習者に興味があり、いろいろ質問します。

質問リスト（順番に聞いてください）:
1. なぜ日本語を勉強しているんですか？
2. どうして日本に来たんですか？
3. 日本の好きなところと苦手なところは？理由も教えてください
4. 将来どうしたいですか？なぜ？

ルール:
- 私の回答に対して「へー、それで？」「どうしてそう思ったんですか？」と深掘りしてください
- 理由の接続（から/ので/て/ため）の使い方が間違っていたら、自然な形で返してください
- 5-7往復の会話をしましょう
- 最後に、私の理由説明で良かった点と改善点を1つずつ教えてください
```
