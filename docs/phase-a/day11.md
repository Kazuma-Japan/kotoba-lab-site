# Day 11: Expressing Feelings（気持ち（きもち）を伝え（つたえ）る）

### ① シナリオ導入（どうにゅう）
Beyond "楽しい（たのしい）" and "嬉しい（うれしい）," how do you express nuanced feelings in Japanese? Today you'll learn to express surprise, worry, relief, and disappointment — the emotions that make conversation real.

**今日（きょう）のゴール**: 喜怒哀楽（きどあいらく）を適切（てきせつ）な表現（ひょうげん）で伝え（つたえ）られるようになる

### ② キーフレーズ & 文法（ぶんぽう）

- **嬉しい（うれしい）** — happy/glad
- **びっくりしました** — I was surprised
- **心配（しんぱい）です** — I'm worried
- **ほっとしました** — I'm relieved
- **残念（ざんねん）です** — That's disappointing / too bad
- **〜てよかった** — I'm glad that ~ / Good thing ~

💡 文法（ぶんぽう）ポイント: 「〜てよかった」は結果（けっか）に対する（たいする）安堵（あんど）。「勉強（べんきょう）してよかった」= "I'm glad I studied." 過去（かこ）の行動（こうどう） + 今（いま）の感情（かんじょう）。

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（易）**
1. I'm happy! → 嬉しい（うれしい）です！
2. I was surprised. → びっくりしました。
3. I'm worried. → 心配（しんぱい）です。
4. That's too bad. → 残念（ざんねん）です。
5. I'm relieved. → ほっとしました。

**Set 2（中）**
1. I'm glad I studied. → 勉強（べんきょう）してよかったです。
2. I was surprised because he suddenly came. → 急に（きゅうに）来た（きた）ので、びっくりしました。
3. I'm worried because the test is tomorrow. → 明日（あした）テストなので、心配（しんぱい）です。
4. It was disappointing that it rained. → 雨（あめ）で残念（ざんねん）でした。
5. I'm relieved that you're okay. → 大丈夫（だいじょうぶ）でよかったです。

**Set 3（難）**
1. I was really worried, but I'm glad it worked out in the end. → すごく心配（しんぱい）だったんですけど、最後（さいご）はうまくいってよかったです。
2. I was surprised because the food at that restaurant was much better than I expected. → あのレストラン、思った（おもった）よりずっとおいしくてびっくりしました。
3. I'm a bit anxious about moving to Japan because I don't know anyone there. → 日本（にほん）に引っ越す（ひっこす）のが少し（すこし）不安（ふあん）です。誰も（だれも）知り合い（しりあい）がいないので。
4. It's too bad the concert was cancelled, but it can't be helped. → コンサートが中止（ちゅうし）になって残念（ざんねん）ですけど、しょうがないですね。
5. I'm glad I came to Japan. Every day is fun. → 日本（にほん）に来て（きて）よかったです。毎日（まいにち）楽しい（たのしい）です。
