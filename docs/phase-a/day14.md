# Day 14: Talking About Abilities（できること）

### ① シナリオ導入（どうにゅう）
Can you use chopsticks? Can you read kanji? Can you cook? Talking about abilities is a great conversation topic — especially as a language learner, where people love asking what you can do.

**今日（きょう）のゴール**: 自分（じぶん）のできること・できないことを表現（ひょうげん）できるようになる

### ② キーフレーズ & 文法（ぶんぽう）

- **〜ができます** — I can do ~
- **〜られます / 〜えます** — potential form (I can ~)
- **〜ようになりました** — I became able to ~ / I've learned to ~
- **まだ〜ない** — I can't ~ yet
- **〜のが得意（とくい）です / 苦手（にがて）です** — I'm good at ~ / bad at ~
- **〜ようにしています** — I'm trying to ~ (habitual effort)

💡 文法（ぶんぽう）ポイント: 「〜ようになりました」は変化（へんか）のプロセスを表す（あらわす）。「日本語（にほんご）が話せ（はなせ）るようになりました」= 前（まえ）はできなかった→今（いま）はできる。

**A**: サムさん、お箸（はし）、上手（じょうず）に使え（つかえ）ますね。
**B**: ありがとうございます。最初（さいしょ）は全然（ぜんぜん）使え（つかえ）なかったんですけど、練習（れんしゅう）して使え（つかえ）るようになりました。
**A**: 漢字（かんじ）は読め（よめ）ますか？
**B**: 簡単（かんたん）な漢字（かんじ）は読め（よめ）ます。でも、まだ難しい（むずかしい）のは読め（よめ）ないです。
**A**: 料理（りょうり）は得意（とくい）ですか？
**B**: 料理（りょうり）は好き（すき）なんですけど、まだ和食（わしょく）は苦手（にがて）です。カレーくらいしか作れ（つくれ）ないです。
**A**: カレーが作れ（つくれ）るなら十分（じゅうぶん）ですよ！

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（易）**
1. I can use chopsticks. → お箸（はし）が使え（つかえ）ます。
2. I can read hiragana. → ひらがなが読め（よめ）ます。
3. I can't write kanji yet. → まだ漢字（かんじ）は書け（かけ）ないです。
4. I can speak a little Japanese. → 日本語（にほんご）が少し（すこし）話せ（はなせ）ます。
5. I'm good at cooking. → 料理（りょうり）が得意（とくい）です。

**Set 2（中）**
1. I've become able to use chopsticks. → お箸（はし）が使え（つかえ）るようになりました。
2. I can read simple kanji, but difficult ones are still hard. → 簡単（かんたん）な漢字（かんじ）は読め（よめ）ますけど、難しい（むずかしい）のはまだダメです。
3. I'm bad at listening, so I try to watch Japanese TV every day. → リスニングが苦手（にがて）なので、毎日（まいにち）日本（にほん）のテレビを見る（みる）ようにしています。
4. I could only make curry before, but now I can make other things too. → 前（まえ）はカレーしか作れ（つくれ）なかったですけど、今（いま）は他の（ほかの）ものも作れ（つくれ）ます。
5. Can you drive in Japan? → 日本（にほん）で運転（うんてん）できますか？

**Set 3（難）**
1. At first I couldn't say anything, but after six months I've become able to have basic conversations. → 最初（さいしょ）は何も（なにも）言え（いえ）なかったんですけど、半年（はんとし）で基本的（きほんてき）な会話（かいわ）ができるようになりました。
2. I'm good at reading but not at speaking. I want to improve my speaking ability. → 読む（よむ）のは得意（とくい）ですけど、話す（はなす）のが苦手（にがて）です。スピーキング力（ちから）を上げ（あげ）たいです。
3. I can understand when people speak slowly, but I can't keep up with native speed. → ゆっくり話し（はなし）てもらえれば分か（わか）りますけど、ネイティブのスピードにはまだついていけないです。
4. I'm trying to think in Japanese instead of translating from English in my head. → 頭（あたま）の中（なか）で英語（えいご）から翻訳（ほんやく）するんじゃなくて、日本語（にほんご）で考え（かんがえ）るようにしています。
5. I can't do everything perfectly, but I think it's important to try. → 完璧（かんぺき）にはできないですけど、やってみることが大事（だいじ）だと思い（おもい）ます。

### ⑤ AI練習（れんしゅう）テンプレート

```
あなたは日本語学校の先生「高橋先生」です。新しい生徒（私）の日本語力を把握するためにカジュアルなインタビューをしています。

質問リスト（順番に聞いてください）:
1. 日本語はどのくらい勉強していますか？
2. ひらがな・カタカナ・漢字、どこまで読めますか？
3. 日本語で一番得意なことは何ですか？
4. 逆に、一番苦手なことは？
5. 最近できるようになったことはありますか？

ルール:
- 私の回答に対して「すごいですね！」「頑張っていますね」等のリアクションをしてください
- 可能形（〜られる/〜える）の使い方が間違っていたら、やさしく訂正してください
- 5-7往復の会話をしましょう
- 最後に、私の能力表現で良かった点と改善点を1つずつ教えてください
```
