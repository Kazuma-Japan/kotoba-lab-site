# Day 9: Talking About the Past（過去（かこ）の話（はなし））

### ① シナリオ導入（どうにゅう）
Your colleague asks about your weekend, your trip, or something you did recently. Past tense is where conversations get interesting — you can share experiences and stories.

**今日（きょう）のゴール**: 過去（かこ）の出来事（できごと）を時系列（じけいれつ）で説明（せつめい）できるようになる

### ② キーフレーズ & 文法（ぶんぽう）

- **〜ました** — did ~ (polite past)
- **〜かったです / 〜でした** — was ~ (i-adj / na-adj past)
- **〜たことがあります** — I have done ~ (experience)
- **〜た時（とき）** — when I did ~
- **〜たら** — when ~ happened (unexpected result)
- **初めて（はじめて）** — for the first time

💡 文法（ぶんぽう）ポイント: 「〜たことがあります」は人生（じんせい）で一度（いちど）でも経験（けいけん）があるかどうか。「富士山（ふじさん）に登っ（のぼっ）たことがありますか？」

**A**: 週末（しゅうまつ）、何を（なにを）しましたか？
**B**: 初めて（はじめて）築地（つきじ）に行き（いき）ました。
**A**: いいですね！どうでしたか？
**B**: すごく楽しか（たのしか）ったです。朝早く（あさはやく）行った（いった）ら、もうたくさん人（にん）がいました。
**A**: 何を（なにを）食べ（たべ）ましたか？
**B**: マグロの寿司（すし）を食べ（たべ）ました。今まで（いままで）食べた（たべた）中（なか）で一番（いちばん）おいしかったです。
**A**: お寿司（すし）を握る（にぎる）体験（たいけん）をしたことはありますか？
**B**: まだないです。今度（こんど）やってみたいです。

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（易）**
1. I went to Shibuya yesterday. → 昨日（きのう）、渋谷（しぶや）に行き（いき）ました。
2. It was fun. → 楽しか（たのしか）ったです。
3. I ate ramen. → ラーメンを食べ（たべ）ました。
4. I watched a movie. → 映画（えいが）を見ま（みま）した。
5. The weather was good. → 天気（てんき）がよかったです。

**Set 2（中）**
1. I went to Tsukiji for the first time. → 初めて（はじめて）築地（つきじ）に行き（いき）ました。
2. When I went early in the morning, there were already many people. → 朝早く（あさはやく）行った（いった）ら、もうたくさん人（にん）がいました。
3. It was the best sushi I've ever had. → 今まで（いままで）食べた（たべた）中（なか）で一番（いちばん）おいしい寿司（すし）でした。
4. Have you ever climbed Mt. Fuji? → 富士山（ふじさん）に登っ（のぼっ）たことがありますか？
5. Last weekend was quiet — I just stayed home. → 先週末（せんしゅうまつ）は静か（しずか）でした。ずっと家（いえ）にいました。

**Set 3（難）**
1. I tried natto for the first time, but it wasn't as bad as I expected. → 初めて（はじめて）納豆（なっとう）を食べて（たべて）みましたけど、思った（おもった）ほど悪く（わるく）なかったです。
2. When I went to Kyoto, it was raining, but the temples were still beautiful. → 京都（きょうと）に行った（いった）時（とき）、雨（あめ）でしたけど、お寺（てら）はやっぱりきれいでした。
3. I studied a lot before the test, but it was still difficult. → テストの前（まえ）にたくさん勉強（べんきょう）しましたけど、やっぱり難しか（むずかしか）ったです。
4. I've been to Japan three times. The first time was five years ago. → 日本（にほん）に3回（かい）来た（きた）ことがあります。最初（さいしょ）は5年前（ねんまえ）でした。
5. I was going to go to the park, but it started raining so I stayed home. → 公園（こうえん）に行く（いく）つもりだったんですけど、雨（あめ）が降っ（ふっ）てきたので、家（いえ）にいました。

### ⑤ AI練習（れんしゅう）テンプレート

```
あなたは私の日本人の同僚です。月曜日の朝、オフィスで「週末どうでしたか？」と聞いてきます。

ルール:
- 私の話に興味を持って「それで？」「どうだった？」と掘り下げてください
- あなたの週末のことも話してください（映画を見た、公園に行った、等）
- 過去形の使い方が間違っていたら、正しい形で自然に返してください
- 5-7往復の会話をしましょう
- 最後に、私の過去形の使い方で良かった点と改善点を1つずつ教えてください
```
