# Day 13: Saying Yes, No, and Maybe（はい・いいえ・微妙（びみょう））

### ① シナリオ導入（どうにゅう）
In English, "no" is just "no." In Japanese, saying "no" directly is often too blunt. Today you'll learn how Japanese people actually decline, agree, and express uncertainty — this is where cultural understanding meets language.

**今日（きょう）のゴール**: 日本語（にほんご）で自然（しぜん）に承諾（しょうだく）・断り（ことわり）・曖昧（あいまい）な返事（へんじ）ができるようになる

### ② キーフレーズ & 文法（ぶんぽう）

- **もちろん / ぜひ** — Of course / Absolutely (strong yes)
- **いいですよ** — Sure, that's fine
- **ちょっと難しい（むずかしい）です** — That's a bit difficult (= No)
- **考え（かんがえ）ておきます** — I'll think about it (= probably No)
- **〜かもしれません** — Maybe / It might be ~
- **微妙（びみょう）ですね** — Hmm, that's iffy / not sure

💡 文法（ぶんぽう）ポイント: 日本語（にほんご）の「No」は直接（ちょくせつ）言わ（いわ）ない。「ちょっと...」だけで断り（ことわり）が成立（せいりつ）する。「金曜日（きんようび）空い（あい）てる？」→「金曜日（きんようび）はちょっと...」= No。

**A**: あ、あとケンも誘っ（さそっ）ていい？
**B**: うーん、ケンかぁ...。まあ、いいんじゃない？

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（易）**
1. Of course! → もちろん！
2. Sure, that's fine. → いいですよ。
3. That's a bit difficult. → ちょっと難しい（むずかしい）です。
4. Maybe. → かもしれません。
5. I'll think about it. → 考え（かんがえ）ておきます。

**Set 2（中）**
1. Friday is a bit tough for me. How about Saturday? → 金曜日（きんようび）はちょっと難しい（むずかしい）です。土曜日（どようび）はどうですか？
2. Yes, absolutely! I'd love to go! → はい、ぜひ！行き（いき）たいです！
3. Hmm, I'm not sure about that restaurant. → うーん、あのレストランは微妙（びみょう）ですね。
4. That might be a good idea. → それはいい考え（かんがえ）かもしれません。
5. I don't mind either way. → どっちでもいいですよ。

**Set 3（難）**
1. I'd love to, but I have plans that day, so unfortunately I can't. → 行き（いき）たいんですけど、その日（にち）は予定（よてい）があるので、残念（ざんねん）ですけど行け（いけ）ないです。
2. Hmm, it's not that I don't like it, but it's not really my thing. → うーん、嫌い（きらい）じゃないんですけど、あんまり得意（とくい）じゃないんですよね。
3. I can probably make it, but I'll let you know for sure later. → たぶん大丈夫（だいじょうぶ）だと思い（おもい）ますけど、後で（あとで）ちゃんと連絡（れんらく）します。
4. I'll pass this time, but please invite me again next time! → 今回（こんかい）はやめておきます。でも、また次回（じかい）誘っ（さそっ）てください！
5. It depends on the situation, so I can't say yes right now. → 状況次第（じょうきょうしだい）なので、今（いま）ははっきり言え（いえ）ないです。

```
あなたの提案（ランダムに出してください）:
- カラオケに行かない？
- 今度一緒に料理しない？

- 1つずつ提案してください

- 私が曖昧表現を上手に使えたら褒めてください
- 5-7往復の会話をしましょう
- 最後に、私の承諾・断りの表現で良かった点と改善点を1つずつ教えてください
```
