# Day 56: Giving a Short Presentation（プレゼンする）

### ① シナリオ導入（どうにゅう）
You need to give a short introduction at a meetup, explain your project to a group, or pitch an idea. Public speaking in Japanese follows a clear structure. Today you'll learn the pattern: greeting → topic → main points → summary → closing.

**今日（きょう）のゴール**: 3分間（ふんかん）の短い（みじかい）プレゼンを日本語（にほんご）で構成（こうせい）・発表（はっぴょう）できるようになる

### ② キーフレーズ & 文法（ぶんぽう）

- **今日は（こんにちは）〜についてお話し（はなし）します** — Today I'll talk about ~
- **まず / 次に（つぎに） / 最後（さいご）に** — First / Next / Finally
- **ポイントは3つあります** — There are 3 key points
- **具体的（ぐたいてき）に言う（いう）と** — Specifically / To be concrete
- **まとめると** — To summarize
- **ご質問（しつもん）はありますか？** — Are there any questions?

💡 文法（ぶんぽう）ポイント: 「〜ということです」でまとめるのがプレゼンの締め（しめ）。「つまり、日本語（にほんご）は楽しい（たのしい）ということです」= "In other words, Japanese is fun." 最後（さいご）のメッセージを明確（めいかく）に。

### ③ モデル会話（かいわ）（プレゼン例（れい））

**サム**: みなさん、こんにちは。サムといいます。今日は（こんにちは）「外国人（がいこくじん）が日本語（にほんご）を学ぶ（まなぶ）べき3つの理由（りゆう）」についてお話し（はなし）します。

ポイントは3つあります。

まず1つ目（め）は、日本語（にほんご）を話す（はなす）と日本（にほん）での体験（たいけん）が10倍（ばい）楽しく（たのしく）なるということです。具体的（ぐたいてき）に言う（いう）と、地元（じもと）の人（にん）と話せ（はなせ）るようになるので、ガイドブックには載っ（のっ）ていない場所（ばしょ）やお店（みせ）を教え（おしえ）てもらえます。

次に（つぎに）2つ目（め）は、脳（のう）にいいということです。研究（けんきゅう）によると、漢字（かんじ）を学ぶ（まなぶ）ことで脳（のう）の視覚的（しかくてき）な処理能力（しょりのうりょく）が向上（こうじょう）するそうです。

最後（さいご）に3つ目（め）は、キャリアに有利（ゆうり）だということです。日本語（にほんご）ができるビジネスパーソンの需要（じゅよう）は増え（ふえ）ています。

まとめると、日本語（にほんご）は「楽しい（たのしい）」「脳（のう）にいい」「キャリアに役立つ（やくたつ）」の3点（てん）で学ぶ（まなぶ）価値（かち）があるということです。

ご質問（しつもん）はありますか？

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（プレゼンのフレーズ）**
1. Today I'll talk about ~. → 今日は（こんにちは）〜についてお話し（はなし）します。
2. There are 3 key points. → ポイントは3つあります。
3. First... Next... Finally... → まず... 次に（つぎに）... 最後（さいご）に...
4. To summarize... → まとめると...
5. Are there any questions? → ご質問（しつもん）はありますか？

**Set 2（内容（ないよう）を伝え（つたえ）る）**
1. Specifically, being able to speak Japanese makes travel in Japan 10 times more enjoyable. → 具体的（ぐたいてき）に言う（いう）と、日本語（にほんご）が話せ（はなせ）ると日本（にほん）での旅行（りょこう）が10倍（ばい）楽しく（たのしく）なります。
2. According to research, learning kanji improves visual processing in the brain. → 研究（けんきゅう）によると、漢字（かんじ）を学ぶ（まなぶ）ことで脳（のう）の視覚的（しかくてき）処理能力（しょりのうりょく）が向上（こうじょう）するそうです。
3. In other words, Japanese is worth learning for three reasons. → つまり、日本語（にほんご）は3つの理由（りゆう）で学ぶ（まなぶ）価値（かち）があるということです。
4. Let me give you an example. → 例（れい）を挙げ（あげ）ます。
5. This is an important point. → ここは重要な（じゅうような）ポイントです。

**Set 3（Q&A対応（たいおう））**
1. That's a great question. → いい質問（しつもん）ですね。
2. I'm not sure about the exact number, but approximately... → 正確（せいかく）な数字（すうじ）はわかりませんが、おおよそ...
3. To answer your question, I think... → ご質問（しつもん）にお答え（こたえ）すると、〜だと思い（おもい）ます。
4. I'll look into that and get back to you. → 調べ（しらべ）てからお答え（こたえ）します。
5. Does that answer your question? → ご質問（しつもん）の答え（こたえ）になっていますか？

### ⑤ AI練習（れんしゅう）テンプレート

```
今日は私がミニプレゼンをします。あなたは聴衆の1人です。

私のプレゼンテーマ:「外国人として日本に住む良い点と大変な点」(3分以内)

ルール:
- 私がプレゼンを始めたら、途中で止めないでください
- プレゼン終了後に質問を2-3個してください
- その後、プレゼンのフィードバックをしてください:
  - 構成（導入→本論→まとめの流れ）
  - 言語（敬語の適切さ、接続表現）
  - 内容（具体例の有無、説得力）
  - 改善ポイント
```
