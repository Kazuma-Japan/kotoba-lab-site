# Day 58: Japanese Internet & SNS Language（ネット用語（ようご）・スラング）

### ① シナリオ導入（どうにゅう）
LOL = 笑（わらい）, NGL = ぶっちゃけ, It's giving = 〜み. Every language has internet slang. If you want to understand Japanese social media, memes, and casual online conversations, you need to know these. Today you go beyond textbook Japanese.

**今日（きょう）のゴール**: 日本語（にほんご）のネットスラング・SNS用語（ようご）を理解（りかい）し、適切（てきせつ）に使え（つかえ）るようになる

### ② キーフレーズ & 文法（ぶんぽう）

- **w / 草（くさ）** — LOL (laughing)
- **それな** — That's so true / Fr fr
- **推し（おし）** — my fave / who I stan
- **エモい** — emotional / aesthetic / vibes
- **ガチ** — for real / seriously
- **〜み** — ~ness / ~vibes (suffix that turns adjectives into nouns)

💡 文法（ぶんぽう）ポイント: 「w」は「笑い（わらい）」(warai)の略（りゃく）。wwwwは大笑い（おおわらい）。「草（くさ）」は「www」が草原（そうげん）に見え（みえ）るから。「草生（そうせい）える」= "I'm dying laughing." SNS/LINEでは使う（つかう）が、仕事（しごと）では絶対（ぜったい）NG。

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（ネットスラング基礎（きそ））**
1. LOL → w / 草（くさ）
2. That's so true. → それな。
3. For real / Seriously → ガチ / マジ
4. My favorite (idol/character) → 推し（おし）
5. Emotional / Aesthetic → エモい

**Set 2（SNSで使う（つかう））**
1. This is hilarious LOL → これ面白す（おもしろす）ぎるwww
2. I seriously can't deal with this. → ガチで無理（むり）なんだけど。
3. The vibes of this cafe are amazing. → このカフェ、雰囲気（ふんいき）エモい。
4. I totally get what you mean. → わかりみが深い（ふかい）。
5. My fave's new song made me cry. → 推し（おし）の新曲（しんきょく）で泣い（ない）た。

**Set 3（カジュアルな会話（かいわ）で自然（しぜん）に使う（つかう））**
1. I was told my Japanese is good for the 15th time this month. I seriously can't anymore LOL. → 今月（こんげつ）15回目（かいめ）の「日本語（にほんご）上手（じょうず）ですね」。ガチでもう笑う（わらう）www
2. Have you seen this video? It's so wholesome, I'm literally crying. → この動画（どうが）見た（みた）？エモすぎて泣い（ない）てるんだけど。
3. My friend is such an otaku. They spend all their money on their fave's merch. → 友達（ともだち）がガチのオタクで、推し（おし）のグッズに全部（ぜんぶ）お金（きん）使って（つかって）るw
4. Online Japanese and textbook Japanese are like two different languages. → ネットの日本語（にほんご）と教科書（きょうかしょ）の日本語（にほんご）って、もはや別の（べつの）言語（げんご）だよね。
5. When I finally understood a Japanese meme without looking up any words, I felt like I had reached a new level. → 日本語（にほんご）のミームを単語（たんご）を調べ（しらべ）ないで理解（りかい）できた時（とき）、レベルアップした気が（きが）した。
