# Day 38: Expressing Conditions（条件（じょうけん）を言う（いう））

### ① シナリオ導入（どうにゅう）
"If it rains..." "When I finish work..." "As long as..." Conditions are everywhere in daily conversation. Japanese has four main conditional forms, and today you'll learn when to use each one.

**今日（きょう）のゴール**: 〜たら/〜ば/〜と/〜なら の4つの条件（じょうけん）表現（ひょうげん）を使い分け（つかいわけ）られる

### ② キーフレーズ & 文法（ぶんぽう）

- **〜たら** — If/When ~ happens (most versatile)
- **〜ば** — If ~ (hypothetical condition)
- **〜と** — When ~ (automatic/habitual result)
- **〜なら** — If (it's the case that) ~
- **もし** — If (adds emphasis to any conditional)
- **〜ない限り（かぎり）** — Unless ~

💡 文法（ぶんぽう）ポイント: 迷っ（まよっ）たら「〜たら」を使え（つかえ）ばほぼOK。4つの中（なか）で最も（もっとも）汎用性（はんようせい）が高い（たかい）。「雨（あめ）が降っ（ふっ）たら、家（いえ）にいます」

**A**: 週末（しゅうまつ）、何（なに）する？
**B**: 天気（てんき）がよかったら、海（うみ）に行き（いき）たいな。
**A**: 雨（あめ）だったら？
**B**: 雨（あめ）なら、家（いえ）で映画（えいが）でも見よ（みよ）うかな。
**A**: もし時間（じかん）があれば、一緒に（いっしょに）どう？
**B**: いいね！あ、でも車（くるま）がないと海（うみ）は不便（ふべん）だよね。
**A**: 電車（でんしゃ）で行け（いけ）ば、1時間（じかん）くらいで着く（つく）よ。
**B**: じゃあ、晴れ（はれ）たら電車（でんしゃ）で行こ（いこ）う。

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（易）**
1. If it rains, I'll stay home. → 雨（あめ）が降っ（ふっ）たら、家（いえ）にいます。
2. If you turn right, you'll see the station. → 右（みぎ）に曲がる（まがる）と、駅（えき）が見え（みえ）ます。
3. If you're free, let's hang out. → 暇（ひま）だったら、遊ぼ（あそぼ）う。
4. If you take the express, it's faster. → 急行（きゅうこう）に乗れ（のれ）ば、早い（はやい）ですよ。
5. If it's Kyoto, I recommend autumn. → 京都（きょうと）なら、秋（あき）がおすすめです。

**Set 2（中）**
1. If the weather is nice, I want to go to the beach. → 天気（てんき）がよかったら、海（うみ）に行き（いき）たいです。
2. If you press this button, the machine turns on. → このボタンを押す（おす）と、機械（きかい）がつきます。
3. If you're interested, I'll tell you more. → 興味（きょうみ）があれば、もっと教え（おしえ）ますよ。
4. If it's that restaurant, I've been there before. → あのレストランなら、行った（いった）ことがあります。
5. I'll go unless something comes up. → 何か（なにか）ない限り（かぎり）、行き（いき）ます。

**Set 3（難）**
1. If I had studied harder, I probably would have passed the test. → もっと勉強（べんきょう）していたら、テストに受か（うか）っていたかもしれません。
2. Spring is the best time if you want to see cherry blossoms, but autumn is more beautiful overall. → 桜（さくら）を見た（みた）いなら春（はる）が一番（いちばん）ですけど、全体的（ぜんたいてき）にきれいなのは秋（あき）だと思い（おもい）ます。
3. Unless you practice speaking every day, it's hard to improve. → 毎日（まいにち）話す（はなす）練習（れんしゅう）をしない限り（かぎり）、上達（じょうたつ）するのは難しい（むずかしい）です。
4. If you eat this sushi, you'll never want to eat sushi anywhere else. → この寿司（すし）を食べた（たべた）ら、他の（ほかの）ところでは食べた（たべた）くなくなりますよ。
5. If you're going to Osaka, you should definitely try takoyaki at a street stall — it's completely different from the ones at restaurants. → 大阪（おおさか）に行く（いく）なら、屋台（やたい）のたこ焼き（やき）をぜひ食べて（たべて）ください。お店（みせ）のと全然（ぜんぜん）違い（ちがい）ますよ。

### ⑤ AI練習（れんしゅう）テンプレート

```
あなたは日本旅行のプランナーです。私が旅行の計画について相談します。

流れ:
- 私が「〜に行きたい」「〜がしたい」と言ったら、条件付きのアドバイスをしてください
- 「もし〜なら」「〜だったら」「〜のであれば」等を積極的に使ってください
- 私も条件表現で返す練習をします

例: 「京都に行きたい」→「秋に行くなら、紅葉がきれいですよ。でも混むので、平日に行った方がいいです」

ルール:
- いろいろな条件パターンを会話に織り込んでください
- 5-7往復の会話をしましょう
- 最後に、私の条件表現の使い分けで良かった点と改善点を1つずつ教えてください
```
