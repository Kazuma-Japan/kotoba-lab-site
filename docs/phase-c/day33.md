# Day 33: Making Suggestions（提案（ていあん）する）

### ① シナリオ導入（どうにゅう）
"How about...?" "Why don't we...?" "I suggest..." — making suggestions is how you become an active participant in conversations instead of just answering questions. Today you become the one driving the conversation.

**今日（きょう）のゴール**: 自然（しぜん）な提案（ていあん）表現（ひょうげん）を使って（つかって）会話（かいわ）をリードできるようになる

### ② キーフレーズ & 文法（ぶんぽう）

- **〜たらどうですか？** — How about ~ing?
- **〜たほうがいいですよ** — You should ~ / It would be better to ~
- **〜てみたら？** — Why don't you try ~ing? (casual)
- **〜するのはどうですか？** — What about doing ~?
- **〜おすすめです** — I recommend ~
- **もし〜なら** — If ~ (hypothetical suggestion)

💡 文法（ぶんぽう）ポイント: 「〜た方が（ほうが）いい」はアドバイス。「〜ない方が（ほうが）いい」は警告（けいこく）。「食べた（たべた）方が（ほうが）いい」= "You should eat." 「食べ（たべ）ない方が（ほうが）いい」= "You shouldn't eat."

### ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

**Set 1（易）**
1. How about trying sushi? → 寿司（すし）を食べて（たべて）みたらどうですか？
2. You should study every day. → 毎日（まいにち）勉強（べんきょう）した方が（ほうが）いいですよ。
3. I recommend this restaurant. → このレストランがおすすめです。
4. Why don't you try it? → やってみたら？
5. What about going to Kyoto? → 京都（きょうと）に行く（いく）のはどうですか？

**Set 2（中）**
1. You should practice conversation more. → もっと会話（かいわ）の練習（れんしゅう）をした方が（ほうが）いいと思い（おもい）ますよ。
2. How about using a language exchange app? → 言語（げんご）交換（こうかん）アプリを使って（つかって）みたらどうですか？
3. I recommend talking to yourself in Japanese for 5 minutes every day. → 毎日（まいにち）5分（ふん）、日本語（にほんご）で独り言（ひとりごと）を言う（いう）のがおすすめです。
4. If you like history, you should definitely go to Kamakura. → 歴史（れきし）が好き（すき）なら、ぜひ鎌倉（かまくら）に行った（いった）方が（ほうが）いいですよ。
5. You shouldn't eat too much before bed. → 寝る（ねる）前（まえ）に食べ（たべ）すぎない方が（ほうが）いいですよ。

**Set 3（難）**
1. If you're having trouble with listening, how about watching Japanese dramas with Japanese subtitles? → リスニングが苦手（にがて）なら、日本（にほん）のドラマを日本語字幕（にほんごじまく）で見て（みて）みたらどうですか？
2. Instead of cramming grammar rules, I think it's better to learn through actual conversations. → 文法（ぶんぽう）のルールを詰め込む（つめこむ）よりも、実際（じっさい）の会話（かいわ）の中（なか）で覚え（おぼえ）た方が（ほうが）いいと思い（おもい）ます。
3. If I were you, I'd start with the most common 500 words. That's the fastest way to improve. → 私（わたし）だったら、よく使う（つかう）500語（ご）から始め（はじめ）ますね。それが一番（いちばん）早く（はやく）上達（じょうたつ）する方法（ほうほう）だと思い（おもい）ます。
4. You probably shouldn't take the express if you're not sure which stop to get off at. → どこで降り（おり）るかわからないなら、急行（きゅうこう）より各駅停車（かくえきていしゃ）の方が（ほうが）いいかもしれません。
5. How about we try that new ramen place this weekend? I heard it's really good. → 今週末（こんしゅうまつ）、新しい（あたらしい）ラーメン屋（や）に行って（いって）みるのはどう？すごくおいしいって聞い（きい）たんだけど。

### ⑤ AI練習（れんしゅう）テンプレート

```
あなたは「悩み相談所」の相談員です。いろいろな悩みを持つ人が来ます。

私が以下の悩みを1つずつ相談します。あなたは聞いてから、私に提案を求めてください（「何かいいアドバイスありますか？」等）。私が提案する練習をします。

悩みリスト:
1. 日本語が上達しない
2. 日本で友達ができない
3. 仕事が忙しすぎて趣味の時間がない
4. 健康的な食事をしたいけど料理が苦手

ルール:
- 私の提案に対して「なるほど」「でも〜」と返して、会話を深めてください
- 提案表現（〜した方がいい、〜てみたら、〜のはどう）の使い方を確認してください
- 各悩み3-4往復ずつ
- 最後に、私の提案表現で良かった点と改善点を1つずつ教えてください
```
