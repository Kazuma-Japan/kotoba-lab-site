    Day 46: Casual vs. Polite — Knowing When to Switch（カジュアルと丁寧（ていねい）の使い分け（つかいわけ））

    ① シナリオ導入（どうにゅう）

    You've been using ですます form all along. But in real Japan, people constantly switch between casual and polite depending on who they're talking to. Today you'll learn when to use which — the #1 skill that separates textbook Japanese from real Japanese.

    今日（きょう）のゴール: 相手（あいて）や場面（ばめん）に応じ（おうじ）てカジュアル/丁寧（ていねい）体（からだ）を切り替え（きりかえ）られるようになる

    ② キーフレーズ & 文法（ぶんぽう）

    • 〜だよ / 〜だね — casual sentence enders
    • 〜じゃん — isn't it? (very casual)
    • 〜っけ？ — was it ~? (trying to remember)
    • 〜し — and besides (casual reason connector)
    • 敬語（けいご） → タメ語（ご）への切り替え（きりかえ）シグナル: 「敬語（けいご）やめていい？」「タメ語（ご）で話そ（はなそ）うよ」
    • タメ語（ご）でいいよ — You can speak casually

    💡 文法（ぶんぽう）ポイント: 日本語（にほんご）の切り替え（きりかえ）ルール: ①初対面（しょたいめん）=ですます ②年齢（ねんれい）が近い（ちかい）+何度（なんど）か会っ（あっ）た=カジュアル ③仕事（しごと）の上司（じょうし）=常に（つねに）ですます ④友達（ともだち）=カジュアル。年上（としうえ）→年下（としした）が先に（さきに）「タメ語（ご）でいいよ」と言う（いう）のが一般的（いっぱんてき）。

    ③ モデル会話（かいわ）

    丁寧（ていねい）バージョン: A: 週末（しゅうまつ）は何を（なにを）しましたか？ B: 友達（ともだち）と買い物（かいもの）に行き（いき）ました。渋谷（しぶや）に行って（いって）、服（ふく）を買い（かい）ました。 A: いいですね。何を（なにを）買い（かい）ましたか？

    カジュアルバージョン（同じ（おなじ）内容（ないよう））: A: 週末（しゅうまつ）何（なに）してた？ B: 友達（ともだち）と買い物（かいもの）行って（いって）た。渋谷（しぶや）行って（いって）、服（ふく）買っ（かっ）た。 A: いいじゃん。何（なに）買っ（かっ）たの？

    切り替え（きりかえ）の場面（ばめん）: A: サムさん、もう何回（なんかい）も会っ（あっ）てるし、敬語（けいご）やめていいですか？ B: もちろん！じゃあ、タメ語（ご）で。 A: うん、その方が（ほうが）楽（らく）だよね。

    ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

    Set 1（丁寧（ていねい）→カジュアル変換（へんかん）） 1. 行き（いき）ます → 行く（いく） 2. 食べ（たべ）ました → 食べた（たべた） 3. おいしいです → おいしい 4. 何を（なにを）していますか？ → 何（なに）してるの？ 5. そうですね → そうだね

    Set 2（カジュアルで答え（こたえ）る） 1. What did you do yesterday? → 昨日（きのう）何（なに）してた？ 2. That's nice! → いいじゃん！ 3. Was it that restaurant? → あのレストランだっけ？ 4. I don't want to go. It's far, and I'm tired. → 行き（いき）たくない。遠い（とおい）し、疲れ（つかれ）てるし。 5. Let's speak casually. → タメ語（ご）で話そ（はなそ）うよ。

    Set 3（場面（ばめん）に応じ（おうじ）て切り替え（きりかえ）） 1. (To your boss) I'll finish it by tomorrow. → 明日（あした）までに終わ（おわ）らせます。 2. (To a close friend) I'll finish it by tomorrow. → 明日（あした）までに終わ（おわ）らせるよ。 3. (To a new acquaintance) What kind of work do you do? → どんなお仕事（しごと）をされていますか？ 4. (To a friend) What kind of work do you do? → 仕事（しごと）何（なに）してるの？ 5. (Meeting someone for the 5th time, you want to suggest switching to casual) → もう何回（なんかい）も会っ（あっ）てるし、タメ語（ご）にしない？

    ⑤ AI練習（れんしゅう）テンプレート

    今日は2つのバージョンで同じ会話をします。

【ラウンド1: 丁寧】
あなたは初めて会った日本人の同僚「佐藤さん」です。お互いにですます体で会話します。
テーマ: 週末の過ごし方、趣味、好きな食べ物

【ラウンド2: カジュアル】
設定: 3ヶ月後、佐藤さんとすっかり仲良くなりました。「もうタメ語でいいよ」と言われました。
同じテーマをカジュアルに話し直してください。

ルール:
- 各ラウンド5往復ずつ
- 丁寧→カジュアルの変換で間違いがあったら指摘してください
- 「ここはカジュアルでも敬語の方がいいよ」という場面も教えてください
- 最後に、私の切り替えで良かった点と改善点を1つずつ教えてください
