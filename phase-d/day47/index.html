    Day 47: Basic Keigo — Survival Level（敬語（けいご）サバイバル）

    ① シナリオ導入（どうにゅう）

    Full keigo mastery takes years, but you don't need all of it. Today you'll learn the 80/20 of keigo — the 20% of polite expressions that cover 80% of real-life situations. Think of it as keigo survival kit.

    今日（きょう）のゴール: 最低限（さいていげん）の敬語（けいご）（尊敬語（そんけいご）・謙譲語（けんじょうご））を使え（つかえ）るようになる

    ② キーフレーズ & 文法（ぶんぽう）

    • いらっしゃる — to be / to go / to come (respectful for the other person)
    • おっしゃる — to say (respectful)
    • ご覧（らん）になる — to look / see (respectful)
    • 申す（もうす） / 申し上げ（もうしあげ）る — to say (humble, about yourself)
    • 参る（まいる） — to go / come (humble)
    • いたす — to do (humble)

    💡 文法（ぶんぽう）ポイント: 尊敬語（そんけいご）=相手（あいて）を高め（たかめ）る（いらっしゃる、おっしゃる）。謙譲語（けんじょうご）=自分（じぶん）を低め（ひくめ）る（申す（もうす）、参る（まいる））。迷っ（まよっ）たら「お〜になる」(尊敬（そんけい）)と「お〜する」(謙譲（けんじょう）)のパターンで乗り切れ（のりきれ）る。

    ③ モデル会話（かいわ）

    上司（じょうし）: 田中（たなか）さんは今日（きょう）いらっしゃいますか？ 部下（ぶか）: 田中（たなか）は本日（ほんじつ）外出（がいしゅつ）しております。3時（じ）ごろ戻る（もどる）予定（よてい）です。 上司（じょうし）: そうですか。戻っ（もどっ）たら私（わたし）のところに来る（くる）ように伝え（つたえ）てください。 部下（ぶか）: かしこまりました。田中（たなか）が戻り（もどり）ましたらお伝え（つたえ）いたします。 上司（じょうし）: あと、このレポート、ご覧（らん）になりましたか？ 部下（ぶか）: はい、拝見（はいけん）いたしました。いくつか修正箇所（しゅうせいかしょ）があると思い（おもい）まして。 上司（じょうし）: では、修正案（しゅうせいあん）を出し（だし）てください。 部下（ぶか）: はい、明日（あした）までに提出（ていしゅつ）いたします。

    ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

    Set 1（基本（きほん）の敬語（けいご）） 1. Is the manager here? → 部長（ぶちょう）はいらっしゃいますか？ 2. The manager said so. → 部長（ぶちょう）がそうおっしゃいました。 3. I'll go there now. → 今か（いまか）ら参り（まいり）ます。 4. I'll do it right away. → すぐにいたします。 5. I've already seen it. → 拝見（はいけん）いたしました。

    Set 2（職場（しょくば）シーン） 1. Tanaka is currently out. He should be back around 3. → 田中（たなか）はただいま外出（がいしゅつ）しております。3時（じ）ごろ戻る（もどる）予定（よてい）です。 2. Understood. I'll let him know. → かしこまりました。お伝え（つたえ）いたします。 3. Could you please take a look at this document? → この書類（しょるい）をご覧（らん）いただけますか？ 4. I'll submit it by tomorrow. → 明日（あした）までに提出（ていしゅつ）いたします。 5. I'm sorry, could you say that one more time? → 申し訳（もうしわけ）ございません、もう一度（いちど）おっしゃっていただけますか？

    Set 3（応用（おうよう）） 1. I heard the president said the meeting has been moved to 2 PM. → 社長（しゃちょう）が会議（かいぎ）を2時（じ）に変更（へんこう）するとおっしゃったと伺い（うかがい）ました。 2. I'll look into it and get back to you by the end of the day. → 確認（かくにん）いたしまして、本日中（ほんじつちゅう）にご連絡（れんらく）いたします。 3. Thank you for taking the time to see me today. → 本日（ほんじつ）はお時間（じかん）をいただきまして、ありがとうございます。 4. I'm sorry for the sudden request. Could you please check this? → 急な（きゅうな）お願い（ねがい）で申し訳（もうしわけ）ございません。こちらを確認し（かくにんし）ていただけますか？ 5. Please let me know if there's anything I can do to help. → 何か（なにか）お手伝い（てつだい）できることがございましたら、おっしゃってください。

    ⑤ AI練習（れんしゅう）テンプレート

    あなたは日本の会社の上司「山田部長」です。

私が新入社員として、以下の場面で敬語を使う練習をします:
1. 朝の挨拶 + 今日の予定を報告
2. 会議の時間変更を伝える
3. 書類のチェックを依頼する
4. 外出する上司に「行ってらっしゃいませ」

ルール:
- 部長としてナチュラルに話してください（部長は私に敬語は使わない）
- 私の敬語が間違っていたら「〜の方が自然だよ」とやさしく教えてください
- 「ここはそこまで堅くなくていいよ」という場面も教えてください
- 各場面3-4往復ずつ
- 最後に、私の敬語で良かった点と改善点を1つずつ教えてください
