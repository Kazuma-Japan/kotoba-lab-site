    Day 36: Talking About the Future（未来（みらい）の話（はなし））

    ① シナリオ導入（どうにゅう）

    Dreams, plans, goals — talking about the future requires a different set of grammar than the past. Today you'll learn to express what you plan to do, what you hope will happen, and what you're aiming for.

    今日（きょう）のゴール: 将来（しょうらい）の計画（けいかく）・夢（ゆめ）・目標（もくひょう）を具体的（ぐたいてき）に語れ（かたれ）るようになる

    ② キーフレーズ & 文法（ぶんぽう）

    • 〜つもりです — I plan to / I intend to
    • 〜予定（よてい）です — It's scheduled / planned
    • 〜たいと思って（おもって）います — I'm thinking I'd like to ~
    • 〜ようにしたい — I want to make it so that ~
    • 将来（しょうらい）は — In the future
    • いつか — Someday

    💡 文法（ぶんぽう）ポイント: 「つもり」は個人的な（こじんてきな）意志（いし）、「予定（よてい）」は確定（かくてい）事項（じこう）。「来月（らいげつ）日本（にほん）に行く（いく）つもりです」(planning to) vs 「来月（らいげつ）日本（にほん）に行く（いく）予定（よてい）です」(scheduled to)。

    ③ モデル会話（かいわ）

    A: 将来（しょうらい）の夢（ゆめ）は何で（なんで）すか？ B: いつか日本（にほん）に住み（すみ）たいと思って（おもって）います。できれば京都（きょうと）か鎌倉（かまくら）に。 A: いいですね。いつごろの予定（よてい）ですか？ B: 来年（らいねん）の春（はる）には引っ越す（ひっこす）つもりです。今（いま）、リモートワークの仕事（しごと）を探し（さがし）ています。 A: 日本（にほん）で何を（なにを）するつもりですか？ B: まずは日本語（にほんご）をもっと上達（じょうたつ）させたいです。それから、日本語（にほんご）を使う（つかう）仕事（しごと）を見つ（みつ）けたいと思って（おもって）います。 A: 具体的（ぐたいてき）な計画（けいかく）があるんですね。 B: はい。3年後（ねんご）にはJLPT N1に合格（ごうかく）するようにしたいです。

    ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

    Set 1（易） 1. I plan to go to Japan next year. → 来年（らいねん）日本（にほん）に行く（いく）つもりです。 2. I want to live in Kyoto someday. → いつか京都（きょうと）に住み（すみ）たいです。 3. It's scheduled for next Monday. → 来週（らいしゅう）の月曜日（げつようび）の予定（よてい）です。 4. What are your future goals? → 将来（しょうらい）の目標（もくひょう）は何で（なんで）すか？ 5. I want to study more. → もっと勉強（べんきょう）したいと思って（おもって）います。

    Set 2（中） 1. I'm planning to move to Japan next spring. → 来年（らいねん）の春（はる）に日本（にほん）に引っ越す（ひっこす）つもりです。 2. I'd like to find a job that uses Japanese. → 日本語（にほんご）を使う（つかう）仕事（しごと）を見つ（みつ）けたいと思って（おもって）います。 3. I want to be able to have daily conversations without any problems. → 日常会話（にちじょうかいわ）に困ら（こまら）ないようになりたいです。 4. This year, I'm planning to take the JLPT N3. → 今年（こんねん）、JLPT N3を受ける（うける）予定（よてい）です。 5. I haven't decided on a specific plan yet, but I'd like to try. → まだ具体的（ぐたいてき）な計画（けいかく）は決ま（きま）っていませんけど、やってみたいです。

    Set 3（難） 1. My dream is to open a cafe in Japan that serves American-style coffee and Japanese sweets. → 夢（ゆめ）は、日本（にほん）でアメリカンスタイルのコーヒーと和菓子（わがし）を出す（だす）カフェを開く（ひらく）ことです。 2. Within three years, I want to reach a level where I can watch Japanese movies without subtitles. → 3年（ねん）以内（いない）に、字幕（じまく）なしで日本（にほん）の映画（えいが）を見ら（みら）れるレベルになりたいです。 3. I'm going to try to use Japanese as much as possible every day, even if I make mistakes. → 間違え（まちがえ）てもいいから、毎日（まいにち）できるだけ日本語（にほんご）を使う（つかう）ようにしたいです。 4. Next year I'm planning to travel around Japan for three months. I especially want to visit the rural areas. → 来年（らいねん）3ヶ月（がつ）くらい日本（にほん）を旅行（りょこう）するつもりです。特に（とくに）田舎（いなか）の方（ほう）に行って（いって）みたいです。 5. My short-term goal is to pass N2, and my long-term goal is to work as a translator between English and Japanese. → 短期的（たんきてき）な目標（もくひょう）はN2合格（ごうかく）で、長期的（ちょうきてき）な目標（もくひょう）は英語（えいご）と日本語（にほんご）の翻訳者（ほんやくしゃ）として働く（はたらく）ことです。

    ⑤ AI練習（れんしゅう）テンプレート

    あなたはキャリアカウンセラーの「中村さん」です。私の将来の計画について相談に乗ってください。

流れ:
1. 「今日はどんなことについて相談したいですか？」から始める
2. 私の目標を聞いて、具体的に掘り下げてください（いつまでに？どうやって？）
3. 現実的なアドバイスをしてください
4. 行動計画を一緒に整理してください

ルール:
- 「つもり」「予定」「〜たいと思っている」の使い方を確認してください
- 私が曖昧な場合、「もう少し具体的に言うと？」と深掘りしてください
- 5-7往復の会話をしましょう
- 最後に、私の未来表現で良かった点と改善点を1つずつ教えてください
