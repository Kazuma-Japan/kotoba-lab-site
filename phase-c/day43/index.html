    Day 43: Apologizing & Forgiving（謝る（あやまる）・許す（ゆるす））

    ① シナリオ導入（どうにゅう）

    You're late to meet a friend. You accidentally bump into someone. You forget a promise. Apologizing in Japanese goes far beyond "すみません." Today you'll learn the full spectrum — from light apologies to deep ones, and how to accept them gracefully.

    今日（きょう）のゴール: 状況（じょうきょう）に応じ（おうじ）た適切（てきせつ）な謝り（あやまり）方（ほう）と、謝罪（しゃざい）を受け入れ（うけいれ）る表現（ひょうげん）を身に（みに）つける

    ② キーフレーズ & 文法（ぶんぽう）

    • ごめん / ごめんなさい — Sorry (casual / polite casual)
    • すみません / 申し訳（もうしわけ）ありません — I'm sorry (polite / formal)
    • 〜てしまって、すみません — I'm sorry for having ~
    • 気に（きに）しないでください — Don't worry about it
    • お互い（たがい）様（さま）です — It happens to everyone / We're even
    • 二度（にど）としません — I won't do it again

    💡 文法（ぶんぽう）ポイント: 謝罪（しゃざい）のレベル: ごめん(友達（ともだち）) < すみません(一般（いっぱん）) < 申し訳（もうしわけ）ございません(ビジネス/深刻（しんこく）)。状況（じょうきょう）に合わ（あわ）ないレベルの謝罪（しゃざい）は逆効果（ぎゃくこうか）。

    ③ モデル会話（かいわ）

    A: サムさん、30分（ふん）も遅れ（おくれ）ちゃってごめん！電車（でんしゃ）が止ま（とま）っちゃって。 B: 大丈夫（だいじょうぶ）だよ。そういうこともあるよね。お互い（たがい）様（さま）。 A: 本当（ほんとう）に申し訳ない（もうしわけない）。待た（また）せてしまって。 B: 気に（きに）しないで。もう来た（きた）から大丈夫（だいじょうぶ）。 A: お詫び（わび）に今日（きょう）のランチはおごるよ。 B: えー、いいの？ありがとう。じゃあ、お言葉（ことば）に甘え（あまえ）て。

    ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

    Set 1（易） 1. Sorry! → ごめん！ 2. I'm sorry. → すみません。 3. Don't worry about it. → 気に（きに）しないでください。 4. It happens. → お互い（たがい）様（さま）です。 5. I won't do it again. → 二度（にど）としません。

    Set 2（中） 1. I'm sorry for being late. The train stopped. → 遅れ（おくれ）てしまってすみません。電車（でんしゃ）が止ま（とま）ってしまって。 2. I'm sorry for the trouble I've caused. → ご迷惑（めいわく）をおかけしてすみません。 3. It's fine, really. Don't worry. → 本当（ほんとう）に大丈夫（だいじょうぶ）ですよ。気に（きに）しないでください。 4. As an apology, let me treat you to lunch. → お詫び（わび）に、ランチをおごらせてください。 5. I'm sorry, I completely forgot about our promise. → ごめんなさい、約束（やくそく）を完全（かんぜん）に忘れ（わすれ）てしまいました。

    Set 3（難） 1. I sincerely apologize for the mistake. I should have double-checked before sending it. → 間違い（まちがい）について本当（ほんとう）に申し訳（もうしわけ）ございません。送る（おくる）前（まえ）にもう一度（いちど）確認す（かくにんす）るべきでした。 2. It wasn't your fault at all. Anyone would have done the same thing in that situation. → 全然（ぜんぜん）あなたのせいじゃないですよ。あの状況（じょうきょう）なら誰（だれ）でも同じ（おなじ）ことをしたと思い（おもい）ます。 3. I know saying sorry doesn't fix it, but I truly regret what happened. → すみませんと言って（いって）済む（すむ）問題（もんだい）ではないと分か（わか）っていますが、本当（ほんとう）に後悔（こうかい）しています。 4. Please don't blame yourself. Mistakes happen, and what matters is what we do next. → 自分（じぶん）を責め（せめ）ないでください。間違い（まちがい）は誰（だれ）にでもあります。大事（だいじ）なのは次に（つぎに）どうするかです。 5. I appreciate your apology, and I accept it. Let's move forward. → 謝っ（あやまっ）てくれてありがとうございます。受け入れ（うけいれ）ます。前（まえ）に進み（すすみ）ましょう。

    ⑤ AI練習（れんしゅう）テンプレート

    あなたは私の日本人の友達「あい」です。お互いに謝る練習をしましょう。

シチュエーション（交互にやりましょう）:

1. 私があなたとの約束を忘れてしまった → 私が謝る
2. あなたが私から借りた本を汚してしまった → あなたが謝って、私が許す
3. 私が送ったLINEの内容を間違えてしまった → 私が謝る
4. お互いに時間を勘違いしていた → お互い様パターン

ルール:
- 各シチュエーション3-4往復ずつ
- 謝罪のレベル（ごめん〜申し訳ない）が状況に合っているか確認してください
- 「許す側」の表現も練習させてください
- 最後に、私の謝罪/許容表現で良かった点と改善点を1つずつ教えてください
