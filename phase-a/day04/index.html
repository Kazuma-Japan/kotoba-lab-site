    Day 4: Asking for Help（お願い（ねがい）する）

    ① シナリオ導入（どうにゅう）

    You need to ask someone for a favor — borrowing something, asking for directions, requesting help. Mastering polite requests is one of the most practical skills in daily Japanese.

    今日（きょう）のゴール: 丁寧（ていねい）にお願い（ねがい）・依頼（いらい）ができるようになる

    ② キーフレーズ & 文法（ぶんぽう）

    • すみません — Excuse me (to get attention)
    • 〜てもらえますか？ — Could you ~ for me? (polite request)
    • 〜てくれますか？ — Can you ~ for me? (casual request)
    • 〜てもいいですか？ — May I ~? (asking permission)
    • 〜たいんですけど — I'd like to ~ (but...) (soft request)
    • お願い（ねがい）します — Please (closing a request)

    💡 文法（ぶんぽう）ポイント: 「〜たいんですけど」は直接的（ちょくせつてき）なお願い（ねがい）を避け（さけ）る日本的（にほんてき）テクニック。「写真（しゃしん）を撮り（とり）たいんですけど...」= "I'd like to take a photo (could you help?)"

    ③ モデル会話（かいわ）

    A: すみません、ちょっとお聞き（きき）したいんですけど。 B: はい、何で（なんで）すか？ A: この近く（ちかく）にコンビニはありますか？ B: コンビニですか？あそこの角（かく）を右（みぎ）に曲がる（まがる）と、ローソンがありますよ。 A: ありがとうございます。あと、写真（しゃしん）を撮っ（とっ）てもらえますか？ B: もちろん！いいですよ。 A: ここのボタンを押し（おし）てください。お願い（ねがい）します。 B: はい、撮り（とり）ますよ。はい、チーズ！

    ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

    Set 1（易） 1. Excuse me. → すみません。 2. Could you take a photo? → 写真（しゃしん）を撮っ（とっ）てもらえますか？ 3. May I sit here? → ここに座っ（すわっ）てもいいですか？ 4. Please. → お願い（ねがい）します。 5. Is there a convenience store nearby? → この近く（ちかく）にコンビニはありますか？

    Set 2（中） 1. Could you speak a little more slowly? → もう少し（すこし）ゆっくり話し（はなし）てもらえますか？ 2. I'd like to make a reservation. → 予約（よやく）をしたいんですけど。 3. May I use this pen? → このペン、使って（つかって）もいいですか？ 4. Could you write it down for me? → 書い（かい）てもらえますか？ 5. Could you show me the way? → 道（みち）を教え（おしえ）てくれますか？

    Set 3（難） 1. I'd like to ask you something — is there a good sushi restaurant around here? → ちょっとお聞き（きき）したいんですけど、この辺り（あたり）においしい寿司屋（すしや）はありますか？ 2. Could you repeat that one more time? I didn't catch it. → もう一度（いちど）言って（いって）もらえますか？聞き（きき）取れ（とれ）なかったんです。 3. I'd like to send this to America. How much would it be? → これをアメリカに送り（おくり）たいんですけど、いくらですか？ 4. Could you hold this for a moment? → ちょっとこれ、持っ（もっ）ていてもらえますか？ 5. May I try this on? → これ、試着（しちゃく）してもいいですか？

    ⑤ AI練習（れんしゅう）テンプレート

    あなたは東京の街中にいる親切な日本人です。私が道を歩いていて、いろいろなお願いをします。

シチュエーション（ランダムに選んでください）:
1. 道を聞かれる
2. 写真を撮ってほしいと頼まれる
3. おすすめのレストランを聞かれる
4. Wi-Fiが使えるカフェを聞かれる

ルール:
- 自然な日本語で対応してください
- 私のお願いの丁寧さが足りない場合、より丁寧な言い方をさりげなく使って返してください
- 5-7往復の会話をしましょう
- 最後に、私のリクエスト表現で良かった点と改善点を1つずつ教えてください
