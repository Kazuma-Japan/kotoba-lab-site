    Day 15: Review Day — Putting It All Together（総（そう）まとめ）

    ① シナリオ導入（どうにゅう）

    You've just arrived in Japan. In one day, you'll meet a new person, describe yourself, make plans, go to a restaurant, and navigate small talk. This day combines everything from Day 1-14 into one realistic scenario.

    今日（きょう）のゴール: Day 1-14の全（ぜん）スキルを1つのシナリオで使い（つかい）こなす

    ② キーフレーズ（振り返り（ふりかえり））

    Phase A で学ん（まなん）だ主要（しゅよう）パターン: - 自己紹介（じこしょうかい）: 〜といいます、〜から来ま（きま）した、〜をしています - 日課（にっか）: まず〜、それから〜、〜てから - 好き（すき）嫌い（きらい）: 〜が好き（すき）です、〜はちょっと...、ハマっています - 依頼（いらい）: 〜てもらえますか、〜てもいいですか、〜たいんですけど - 数字（すうじ）: 〜個（こ）/本（ほん）/枚（まい）/人（にん）、いくらですか、〜をください - 天気（てんき）・雑談（ざつだん）: 〜そうです、〜みたいです、〜のに - 描写（びょうしゃ）: 〜くて/で、あまり〜ない、〜と比べ（くらべ）て - 予定（よてい）: 〜ませんか、〜ましょう、〜にしましょう - 過去（かこ）: 〜ました、〜たことがあります、〜てよかった - レストラン: 〜にします、おすすめは？、お会計（かいけい）を - 感情（かんじょう）: 嬉しい（うれしい）、残念（ざんねん）、ほっとしました、〜てよかった - 理由（りゆう）: 〜から/ので、だから、〜ためです - 承諾（しょうだく）・断り（ことわり）: もちろん、ちょっと難しい（むずかしい）です、考え（かんがえ）ておきます - 能力（のうりょく）: 〜ができます、〜ようになりました、得意（とくい）/苦手（にがて）

    ③ モデル会話（かいわ）（総合（そうごう）シナリオ）

    場面（ばめん）: 東京（とうきょう）に着い（つい）たばかり。空港（くうこう）で知り合っ（しりあっ）た日本人（にほんじん）と渋谷（しぶや）で再会（さいかい）。

    A: サムさん！久し（ひさし）ぶり！元気（げんき）ですか？ B: 元気（げんき）です！やっと東京（とうきょう）に来ま（きま）した。嬉しい（うれしい）です。 A: よかったですね。東京（とうきょう）はどうですか？ B: すごく大きく（おおきく）て、びっくりしました。人（にん）が多い（おおい）ですね。 A: アメリカと比べ（くらべ）てどうですか？ B: フロリダより涼しい（すずしい）です。でも、電車（でんしゃ）が複雑（ふくざつ）で、ちょっと大変（たいへん）でした。 A: 慣れ（なれ）ますよ。今日（きょう）、時間（じかん）ありますか？ランチどうですか？ B: ぜひ！おすすめのお店（みせ）、ありますか？ A: ここの近く（ちかく）においしいラーメン屋（や）がありますよ。 B: いいですね。ラーメン大好き（だいすき）です。そこにしましょう。

    ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント（総合（そうごう））

    Set 1（Day 1-5の復習（ふくしゅう）） 1. Nice to meet you. I'm Sam, from Florida. → はじめまして。サムといいます。フロリダから来ま（きま）した。 2. I usually wake up at 7 and go for a run. → だいたい7時（じ）に起き（おき）て、走り（はしり）に行き（いき）ます。 3. I love anime. I've been into One Piece lately. → アニメが大好き（だいすき）です。最近（さいきん）ワンピースにハマっています。 4. Could you speak more slowly? → もう少し（すこし）ゆっくり話し（はなし）てもらえますか？ 5. Three of these, please. How much is it? → これを3つください。いくらですか？

    Set 2（Day 6-10の復習（ふくしゅう）） 1. Nice weather today even though it rained yesterday. → 昨日（きのう）は雨（あめ）だったのに、今日は（こんにちは）いい天気（てんき）ですね。 2. Tokyo is big and convenient, but a bit expensive. → 東京（とうきょう）は大きく（おおきく）て便利（べんり）ですけど、ちょっと高い（たかい）です。 3. Shall we meet at Shibuya station at noon? → 12時（じ）に渋谷駅（しぶやえき）で会い（あい）ましょうか？ 4. I went to Kyoto last year for the first time. It was beautiful. → 去年（きょねん）初めて（はじめて）京都（きょうと）に行き（いき）ました。きれいでした。 5. I'll have the recommended dish and a beer, please. → おすすめと、ビールを1つお願い（ねがい）します。

    Set 3（Day 11-14の復習（ふくしゅう）） 1. I'm glad I came to Japan. Every day is exciting. → 日本（にほん）に来て（きて）よかったです。毎日（まいにち）ワクワクします。 2. I'm studying Japanese because I want to live in Japan someday. → いつか日本（にほん）に住み（すみ）たいので、日本語（にほんご）を勉強（べんきょう）しています。 3. Saturday is a bit tough. How about Sunday instead? → 土曜日（どようび）はちょっと難しい（むずかしい）です。代わり（かわり）に日曜日（にちようび）はどうですか？ 4. I couldn't read kanji at all before, but now I can read a little. → 前（まえ）は全然（ぜんぜん）漢字（かんじ）が読め（よめ）なかったですけど、今（いま）は少し（すこし）読め（よめ）るようになりました。 5. I'm not great at keigo yet, but I'm trying to learn it. → まだ敬語（けいご）が苦手（にがて）ですけど、勉強（べんきょう）するようにしています。

    ⑤ AI練習（れんしゅう）テンプレート（総合（そうごう）ロールプレイ）

    あなたは日本人の「たくや」です。空港でたまたま隣の席だった外国人（私）と友達になり、後日東京で再会しました。

今日の流れ:
1. 渋谷で再会 → 挨拶・近況
2. ランチの場所を相談 → 予定を立てる
3. レストランで注文 → 食事中の雑談（趣味、日本の印象、週末の予定等）
4. 会計 → 次の約束

ルール:
- 全15日分のスキルが自然に使える場面を作ってください
- 私が間違えても流れを止めず、自然な返答の中に正しい形を含めてください
- 10-15往復の少し長めの会話をしましょう
- 最後に、Phase A全体を通しての総合評価をしてください:
  - 上手だった表現ベスト3
  - 改善が必要なポイントベスト3
  - Phase Bに向けてのアドバイス

    Phase A 完了（かんりょう）時の（ときの）確認（かくにん）チェックリスト

    Phase Aを終え（おえ）た学習者（がくしゅうしゃ）が確認す（かくにんす）べきこと:

    • [ ] 自己紹介（じこしょうかい）を30秒（びょう）以内（いない）にスラスラ言え（いえ）る
    • [ ] 1日（にち）のルーティンを5文（ぶん）以上（いじょう）で説明（せつめい）できる
    • [ ] 好き（すき）なもの・苦手（にがて）なものを理由（りゆう）つきで言え（いえ）る
    • [ ] 丁寧（ていねい）にお願い（ねがい）・許可（きょか）を求め（もとめ）られる
    • [ ] 助数詞（じょすうし）を使って（つかって）買い物（かいもの）ができる
    • [ ] 天気（てんき）から雑談（ざつだん）を広げ（ひろげ）られる
    • [ ] 人（にん）や場所（ばしょ）を形容詞（けいようし）で描写（びょうしゃ）できる
    • [ ] 友達（ともだち）と予定（よてい）を立て（たて）られる
    • [ ] 週末（しゅうまつ）の出来事（できごと）を過去形（かこけい）で報告（ほうこく）できる
    • [ ] レストランで注文（ちゅうもん）から会計（かいけい）まで一通り（ひととおり）できる
    • [ ] 嬉しい（うれしい）・残念（ざんねん）・心配（しんぱい）などの感情（かんじょう）を表現（ひょうげん）できる
    • [ ] 理由（りゆう）を「から」「ので」で説明（せつめい）できる
    • [ ] 直接的（ちょくせつてき）でない断り（ことわり）方が（ほうが）できる
    • [ ] 自分（じぶん）のできること・できないことを伝え（つたえ）られる
