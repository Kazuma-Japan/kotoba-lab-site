    Day 29: Drinking with Coworkers（飲み会（のみかい）で）

    ① シナリオ導入（どうにゅう）

    The after-work drinking party (飲み会（のみかい）) is a cornerstone of Japanese social life. There's a whole set of phrases for toasting, pouring, ordering more, and politely leaving. Today you'll survive — and enjoy — your first nomikai.

    今日（きょう）のゴール: 飲み会（のみかい）での乾杯（かんぱい）からお開き（ひらき）までの流れ（ながれ）を自然（しぜん）にこなせる

    ② キーフレーズ & 文法（ぶんぽう）

    • 乾杯（かんぱい）！ — Cheers!
    • とりあえずビールで — Beer for now (the classic first order)
    • お酌（しゃく）しましょうか？ — Shall I pour for you?
    • もう1杯（はい）どうですか？ — How about another one?
    • 飲み放題（のみほうだい） — All-you-can-drink
    • お先に（さきに）失礼（しつれい）します — I'll be heading out first (polite exit)

    💡 文法（ぶんぽう）ポイント: 「とりあえず」は「ひとまず」の意味（いみ）。飲み会（のみかい）では「とりあえずビール」が定番（ていばん）の第一声（だいいっせい）。メニューを見る（みる）前（まえ）にまず言う（いう）。

    ③ モデル会話（かいわ）

    幹事（かんじ）: みなさん、今日は（こんにちは）お疲れ（つかれ）様（さま）でした！飲み放題（のみほうだい）、2時間（じかん）です。まず飲み物（のみもの）を注文（ちゅうもん）しましょう。 A: とりあえずビールで。 B: 私（わたし）もビール。 客（きゃく）C: サムさんは？ サム: 僕（ぼく）もビールでお願い（ねがい）します。 幹事（かんじ）: じゃあ、ビール4つ！...来ま（きま）したね。では、乾杯（かんぱい）！ 全員（ぜんいん）: 乾杯（かんぱい）！ ... (しばらくして) A: サムさん、もう1杯（はい）どうですか？ サム: ありがとうございます。次（つぎ）はハイボールにしようかな。 A: いいですね。お酌（しゃく）しましょうか？ サム: あ、大丈夫（だいじょうぶ）です。自分（じぶん）でやります。ありがとうございます。 ... (終盤（しゅうばん）) サム: すみません、明日（あした）早い（はやい）ので、お先に（さきに）失礼（しつれい）します。今日は（こんにちは）ありがとうございました。 幹事（かんじ）: お疲れ（つかれ）様（さま）でした！気を（きを）つけて帰っ（かえっ）てね。

    ④ 瞬間（しゅんかん）翻訳（ほんやく）スプリント

    Set 1（易） 1. Cheers! → 乾杯（かんぱい）！ 2. Beer for now. → とりあえずビールで。 3. Good work today! → お疲れ（つかれ）様（さま）でした！ 4. How about another one? → もう1杯（はい）どうですか？ 5. I'll be heading out first. → お先に（さきに）失礼（しつれい）します。

    Set 2（中） 1. I'll have a highball for my next drink. → 次（つぎ）はハイボールにします。 2. Shall I pour for you? → お酌（しゃく）しましょうか？ 3. I'm fine — I'll do it myself, thanks. → 大丈夫（だいじょうぶ）です、自分（じぶん）でやります。 4. I can't drink much, so I'll have oolong tea. → あまり飲め（のめ）ないので、ウーロン茶（ちゃ）にします。 5. It's all-you-can-drink for 2 hours, so let's enjoy it! → 飲み放題（のみほうだい）2時間（じかん）なので、楽しみ（たのしみ）ましょう！

    Set 3（難） 1. I have to get up early tomorrow, so I'll just have a few drinks and head out. → 明日（あした）早い（はやい）ので、少し（すこし）だけ飲ん（のん）で帰り（かえり）ます。 2. This place has really good food for a drinking party spot. → この店（みせ）、飲み会（のみかい）の店（みせ）にしてはすごく料理（りょうり）がおいしいですね。 3. I'm not great with alcohol, but the atmosphere is fun so I'm having a good time. → お酒（さけ）は強く（つよく）ないですけど、雰囲気（ふんいき）が楽しい（たのしい）ので、すごく楽しい（たのしい）です。 4. Thank you for organizing tonight. It was really fun! → 今日は（こんにちは）幹事（かんじ）ありがとうございました。すごく楽しか（たのしか）ったです！ 5. Last time I drank too much and couldn't remember how I got home. → この前（まえ）飲み（のみ）すぎて、どうやって帰っ（かえっ）たか覚え（おぼえ）てないんです。

    ⑤ AI練習（れんしゅう）テンプレート

    あなたは私の日本人の同僚たちの1人「まさき」です。金曜日の夜、会社の飲み会に来ています。4人のグループです。

飲み会の流れ:
1. 最初の注文 → 乾杯
2. 料理を注文しながら雑談（仕事の話、趣味の話）
3. お酒が進んで打ち解けた会話
4. お開き

ルール:
- 飲み会特有の表現を自然に使ってください
- 私に質問したり、話を振ったりしてください
- 日本の飲み会文化（お酌、「とりあえずビール」、幹事等）も体験できるようにしてください
- 8-10往復の少し長めの会話をしましょう
- 最後に、私の飲み会日本語で良かった点と改善点を1つずつ教えてください
